Particle motifs

An agent skill that turns a concept, motif or symbol into a field of particles. Pick a form, choose how the particles spread around it, and choose whether it holds still or moves. Everything on this page is drawn live by the skill's single engine file.

1 · Spread: how the particles sit around the form

The same knot, eight ways. A spread sets how far points stray from the form and in what shape.

2 · Motion: static or moving

The same figure-of-eight in each mode. Static draws once and stops; the others run continuously and pause when off screen.

3 · From a concept to a motif

What an agent produces from a one-line brief. Each example names the idea, the form chosen for it, and the spread and motion.
